ПАКЕТ СТИЛЕЙ — как подключить
=================================

В архиве:
  styles/elves.css    — Эльфы
  styles/demons.css   — Демониды
  styles/undead.css   — Нежить
  styles/humans.css   — Люди (светлая тема)
  styles/dwarves.css  — Гномы
  styles/orcs.css     — Орки
  styles/_template.css — шаблон для новых разделов
  styles/loader.js    — загрузчик стилей

ШАГ 1. Загрузи папку styles/ в корень репозитория
  (Add file → Upload files).

ШАГ 2. Открой index.html в репозитории, нажми карандашик (Edit),
  найди в самом низу файла строку </body> и ПЕРЕД ней добавь одну строку:

  <script src="styles/loader.js"></script>

  Затем Commit changes.

ГОТОВО. Теперь:
  — цвета каждого раздела лежат в своём файле styles/<id>.css;
  — новый раздел БЕЗ файла стилей получит авто-палитру из его id;
  — свой цвет для нового раздела: скопируй _template.css, назови
    <id>.css, замени x на id и подбери цвета.

Примечание: расовые стили, оставшиеся внутри index.html, можно не
трогать — файлы из styles/ перекрывают их автоматически.
